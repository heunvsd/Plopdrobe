# Plopdrobe

흰 여백, 상단 중앙의 작은 원본 로고, 클릭에 반응하는 좌우 대칭 타이포그래피.

## 바로 보기

VS Code에서 이 폴더를 열고 터미널에서 `npm run dev`를 실행한 뒤 http://localhost:5173 에 접속하세요. 별도 npm install은 필요 없습니다. 저장하면 브라우저가 자동으로 새로고침됩니다. 이미 실행 중이면 해당 주소만 열면 됩니다.

3D 모델을 불러오려면 위 로컬 서버 또는 VS Code Live Server로 열어 주세요.

## 수정할 곳

- `style.css`: 색상, 상단 로고 크기 및 위치, 폰트, 자간
- `app.js`: 원의 크기와 타원 비율, 그려지는 속도, 최대 문구 점유율
- `copy.js`: 새로 전달한 브랜드 문구 원문 전체. 문구를 자르지 않고 원 크기에 맞는 완결된 문구를 선택합니다.
- `assets/plopdrobe-logo.png`: 다운로드/로고/4x/대지 1@4x.png 원본
- `assets/850395daa5fb48f97045b7f459cd9ba3.woff2`: 지정 웹폰트 (TTF fallback 포함)

## 동작

클릭/터치한 위치와 화면 중앙선을 기준으로 반대편에 같은 크기의 원이 동시에 그려집니다. 원과 타원은 크기와 기울기가 달라지며, 글자는 뒤집히지 않고 각 경로를 따라 읽을 수 있게 배치됩니다. 글자는 화면 크기와 무관하게 22px로 고정합니다. 실제 폰트로 문구 폭을 측정하여 둘레의 68% 이하에 들어가는 원문을 선택합니다. 글자의 alphabetic baseline과 원 윤곽선은 같은 SVG 경로입니다. 자간 -10은 -0.01em입니다.

초기 화면에는 원이 없습니다. 클릭할 때마다 한 쌍씩 계속 쌓이며, 개수 제한으로 기존 원이 자동 삭제되지 않습니다. Home 또는 Escape로 초기화합니다. Tab으로 화면을 선택한 후 Enter/Space로도 그릴 수 있습니다. 동작 줄이기 설정을 지원합니다.

Node.js 18 이상 권장. 3D용 Three.js는 로컬 `vendor/`에서 불러옵니다. 메뉴와 버튼은 지정 Adobe Fonts 키트의 Source Sans Pro를 사용합니다(인터넷 필요). 자간은 -0.01em이며 `--font-ui`와 공통 nav/button/.menu/.ui-text 스타일에 설정했습니다.

상단 메뉴: 왼쪽 Home / Shop / Collections, 오른쪽 Instructions / About / Cart. Source Sans Pro 13px, #858585, 자간 -0.01em. SHOP은 카탈로그로 연결되며 COLLECTIONS는 준비 안내입니다. 결제는 연결되지 않았습니다.

첫 화면 중앙에는 CLICK ANYWHERE, FIND YOUR RHYTHM 안내가 표시됩니다. 첫 클릭과 동시에 원이 그려지고 안내는 0.8초 동안 사라집니다. Home/Escape 초기화 시 다시 표시됩니다. Source Sans Pro를 쓰는 UI는 전체 대문자이며 원형 Garamond 문구의 원래 대소문자는 유지합니다.

클릭/터치/Enter/Space로 원을 만들 때 Web Audio로 합성한 짧은 피아노 느낌의 음이 재생됩니다. 실제 피아노 녹음이 아닙니다. C 메이저 펜타토닉 음계에서 무작위 선택하며 같은 음이 연속되지 않습니다. Instructions의 SOUND ON/OFF로 끌 수 있고 설정을 기억합니다. 페이지 진입 시 자동 재생하지 않습니다.

SHOP: SIMULATION 링크와 가구 카테고리 필터. `shop.js`의 PRODUCTS에서 제품 이름·가격·이미지·카테고리를 수정할 수 있습니다. 현재 PLOP 01 — COAT STAND / KRW 0은 임시값입니다. 제품 이미지는 Group 26.png 원본입니다. 상품 클릭 시 상세 화면이 열리고 장바구니에 담을 수 있지만 결제는 연결되지 않았습니다. #shop/all 주소와 뒤로 가기를 지원합니다.


## SIMULATION

SHOP을 누르면 전체 상품 화면이 먼저 열립니다. 상단 보조 메뉴의 ALL ITEMS도 같은 화면으로 돌아가며 카테고리 필터를 초기화합니다. 그 아래 SIMULATION 메뉴 또는 `http://localhost:5173/#simulation`으로 이동하면 GLB 4개를 자동으로 불러옵니다. 시작 버튼이나 모델 카드 없이 실제 모델 자체를 드래그합니다. 로컬 Three.js 라이브러리와 라이선스는 `vendor/`, 원본 GLB와 장착 좌표는 `assets/simulation/`에 있습니다.

- 본체의 받침/중앙 기둥/링은 고정합니다. 원본 GLB 안의 Rod_Left와 Rod_Right를 각각 분리해 서로 다른 각도로 바닥에 눕혀 놓았습니다.
- 봉·옷·모자는 처음부터 바닥에 놓이며, 바닥 그림자와 모델 그림자는 끕니다. 봉은 한 개씩 집어서 본체에 조립합니다. 외투와 모자는 가까운 빈 나무봉 어느 쪽에도 걸 수 있습니다. 가방은 봉과 무관하게 링에만 걸립니다. 포인터 또는 물건이 봉의 넓은 주변 범위에 들어오면 놓는 순간 연결합니다.
- 장착 위치를 미리 보여 주는 원과 모델 잔상은 없습니다. 올바른 드롭에는 0.79초 lift-and-settle 및 작은 흔들림을 적용합니다.
- 드래그 후 손을 떼는 정확한 화면 좌표와 좌우 대칭 좌표에 홈 화면과 같은 파란 원/타원과 Garamond 문구를 그립니다. 크기·기울기·문구는 무작위이며 22px 글자와 윤곽선에 닿는 베이스라인을 유지합니다. 이미 그린 원은 누적됩니다.
- 잘못된 드롭과 포인터 취소는 드래그 시작 위치로 돌아갑니다. 장착된 물건은 제품에서 좌우로 충분히 떨어진 흰 여백에 내려놓아 분리할 수 있습니다. 각 봉을 빼기 전에는 그 봉에 걸린 물건만 먼저 내려놓습니다.
- RESET은 모든 물건과 누적된 원형 문구를 초기화합니다. 화면을 떠나도 조립 상태와 원형 문구를 유지하며, 다시 들어오면 이어서 사용할 수 있습니다. Tab으로 나타나는 대체 조작 버튼도 지원합니다.
- 메인 코드 `simulation.mjs`, 배치 규칙/모션 계산 `simulation-rules.mjs`. 고정된 천 주름 GLB의 위치·회전 애니메이션이며 실시간 천 물리 시뮬레이션은 아닙니다.

## Instructions / About / Cart

상단 오른쪽 메뉴는 각각 `#instructions`, `#about`, `#cart`의 독립된 페이지로 연결됩니다. 브라우저 뒤로 가기와 직접 주소 접속도 지원합니다. Source Sans Pro, 대문자, 자간 -0.01em을 공통 적용했습니다. Instructions와 About 소개 본문은 빈 줄 없이 하나의 문단으로 이어집니다.

- Instructions: 왼쪽 제목과 오른쪽 소개문, 넓은 여백 뒤에 01 / Drape · 02 / Hang · 03 / Place 순으로 배치합니다. 각 제목 아래에 4:5 비율 X 이미지 자리가 있고 바로 아래에 제공된 본문이 들어갑니다. Try it in Simulation 링크는 3D 화면을 바로 엽니다. SOUND ON/OFF도 이 페이지 하단에서 조절합니다.
- About: 전면 배경 위 흰색 본문 구성입니다. 배경은 이미지가 준비될 때까지 회색 X 표시로 두었습니다. `index.html`의 `.about-backdrop`과 각 `.image-placeholder` 자리를 이미지로 교체하면 됩니다.
- Cart: 상품 이미지, 수량 조절, 삭제, 검정 합계 바를 표시합니다. 이 브라우저의 같은 사이트 주소에서 장바구니를 로컬 저장하고 새로고침 후에도 복원합니다. 가격은 기존 임시값이며 결제는 아직 연결하지 않았습니다.
